# Документация класса TimerService

## 1. Общая информация
- **Имя класса:** `TimerService`
- **Тип:** Service (Bound Service / Привязанный сервис)
- **Назначение:** Этот класс демонстрирует работу "привязанного сервиса". Он выполняет роль фонового счетчика секунд. В отличие от обычного сервиса, привязанный сервис предназначен для тесного общения с Activity (как клиент-сервер).
- **Взаимодействие:** `MainActivity` "привязывается" к этому сервису, чтобы получать от него данные (значение таймера). Сервис живет до тех пор, пока к нему привязана хотя бы одна Activity.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `binder` | `IBinder` | Интерфейс ("мостик"), через который Activity может общаться с сервисом. | Возвращается в методе `onBind()`. |
| `executor` | `ExecutorService` | Фоновый поток, в котором работает цикл отсчета секунд. | Инициализируется и запускается в `onCreate()`. |
| `timerValue` | `int` | Хранит текущее количество прошедших секунд. | Увеличивается в цикле; возвращается методом `getTimerValue()`. |
| `isRunning` | `boolean` | Флаг, который позволяет остановить цикл отсчета. | Проверяется в условии цикла `while`. |

## 3. Методы класса

### Имя метода: `onCreate`
- **Тип:** `public`
- **Возвращаемое значение:** `void`
- **Что делает:** 
    1. Инициализирует фоновый поток.
    2. Запускает бесконечный цикл: подождать 1 секунду -> увеличить `timerValue` -> вывести в лог.
- **Когда вызывается:** Один раз при создании сервиса системой.

### Имя метода: `onBind`
- **Тип:** `public`
- **Возвращаемое значение:** `IBinder`
- **Параметры:** `Intent intent`
- **Что делает:** Возвращает объект `binder`. Это как передать Activity "ключ" или "пульт управления" сервисом.
- **Когда вызывается:** Когда `MainActivity` вызывает метод `bindService()`.

### Имя метода: `getTimerValue` (Публичный метод)
- **Тип:** `public`
- **Возвращаемое значение:** `int` (Текущее значение таймера)
- **Что делает:** Просто возвращает число, накопленное в переменной `timerValue`.
- **Когда вызывается:** Вручную из `MainActivity`, когда пользователь нажимает кнопку "Получить значение таймера".

## 4. Жизненный цикл (Только для Service)
- **`onCreate()`:** Запуск фоновой работы (отсчета).
- **`onBind()`:** Установление связи с Activity.
- **`onUnbind()`:** Разрыв связи (когда пользователь нажал "отключиться").
- **`onDestroy()`:** Остановка потока и полная очистка памяти.

## 5. Взаимодействие с интерфейсом (UI)
У этого класса нет своего интерфейса. Он является **источником данных** для графического интерфейса `MainActivity`.

## 6. Взаимодействие с другими компонентами
- **MainActivity:** Подключается через специальный объект `ServiceConnection`. Использует методы сервиса для обновления экрана.

## 7. Общая логика класса
Сервис работает как фоновый секундомер. Ему "все равно", видит его кто-то или нет — он просто считает. Когда Activity подключается к нему, это похоже на подключение монитора к секундомеру, чтобы увидеть цифры.

**Пример использования:**
1. Пользователь нажимает "Подключиться к сервису".
2. `MainActivity` связывается с `TimerService`.
3. `TimerService` начинает считать (1, 2, 3...).
4. Пользователь нажимает "Узнать время".
5. `MainActivity` запрашивает число у сервиса и выводит его в лог.
6. Пользователь нажимает "Отключиться". Сервис останавливается и исчезает из памяти.

## 8. Объяснение простыми словами
Представьте, что `TimerService` — это **Метеостанция** у вас во дворе.
- Станция (Сервис) стоит на улице и постоянно измеряет температуру (считает секунды).
- Вы находитесь в доме (Activity).
- Когда вы хотите узнать температуру, вы втыкаете провод от экрана (Bind) в станцию.
- Если вы выдерните провод, станция перестанет работать, потому что ее данные больше некому смотреть.

---
**Совет для студента:** Привязанные сервисы хороши для задач, которые должны работать только пока пользователь смотрит на конкретный экран. Если задача должна продолжаться после выхода из приложения, используйте Foreground Service или WorkManager.
