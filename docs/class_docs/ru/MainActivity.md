# Документация класса MainActivity

## 1. Общая информация
- **Имя класса:** `MainActivity`
- **Тип:** Activity (Активность/Экран)
- **Назначение:** Этот класс является главной панелью управления приложением. Он отвечает за отображение интерфейса, обработку нажатий кнопок для запуска различных фоновых задач и показ логов (журнала действий) пользователю в реальном времени.
- **Взаимодействие:** Взаимодействует с `MusicPlayerService` (запуск музыки), `TimerService` (получение данных таймера), `WorkManager` (планирование задач) и `MyAsyncTask` (демонстрация старых способов работы в фоне).

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `logTextView` | `TextView` | Поле для вывода текстовых сообщений пользователю. | В методе `log()` для отображения текста на экране. |
| `asyncProgressBar` | `ProgressBar` | Индикатор прогресса для демонстрации `AsyncTask`. | Передается в конструктор `MyAsyncTask`. |
| `mainHandler` | `Handler` | Инструмент для отправки задач в главный (UI) поток. | Для безопасного обновления интерфейса из фоновых потоков. |
| `singleThreadExecutor`| `ExecutorService`| Исполнитель, который выполняет задачи строго по очереди. | В "Модуле 1" для последовательного запуска задач. |
| `fixedThreadPool` | `ExecutorService`| Пул из 4 потоков для одновременного выполнения задач. | В "Модуле 1" для параллельного выполнения. |
| `timerService` | `TimerService` | Ссылка на привязанный сервис таймера. | Для получения текущего значения счетчика. |
| `isBound` | `boolean` | Флаг: подключены ли мы сейчас к `TimerService`. | Проверяется перед попыткой обращения к сервису. |

## 3. Методы класса

### Имя метода: `onCreate`
- **Тип:** `protected`
- **Возвращаемое значение:** `void` (ничего)
- **Параметры:** `Bundle savedInstanceState` (Сохраненное состояние экрана)
- **Что делает:** 
    1. Устанавливает макет экрана (`setContentView`).
    2. Инициализирует визуальные элементы (кнопки, текстовые поля).
    3. Создает исполнителей (пулы потоков) для фоновой работы.
    4. Настраивает обработчики нажатий кнопок.
- **Когда вызывается:** Автоматически системой Android при запуске приложения.
- **Что важно понимать:** Это "входная дверь" в приложение. Если здесь делать слишком много работы (например, тяжелые вычисления), приложение будет долго открываться.

### Имя метода: `log`
- **Тип:** `public`
- **Возвращаемое значение:** `void`
- **Параметры:** `String message` (Текст для вывода)
- **Что делает:** 
    1. Узнает имя текущего потока, в котором выполняется код.
    2. Использует `runOnUiThread`, чтобы безопасно добавить текст в `logTextView`.
- **Когда вызывается:** Вручную из любого места кода, когда нужно что-то сообщить пользователю.
- **Что важно понимать:** Этот метод "потокобезопасен". Обновлять интерфейс напрямую из фонового потока нельзя — приложение вылетит, поэтому используется специальный механизм переключения на главный поток.

## 4. Жизненный цикл (Только для Activity)
- **`onCreate()`:** Вызывается при создании экрана. Здесь мы все подготавливаем.
- **`onDestroy()`:** Вызывается перед окончательным закрытием экрана. **Очень важно:** здесь мы останавливаем все фоновые потоки и отключаемся от сервисов, чтобы приложение не тратило заряд батареи впустую и не вызывало ошибок.

## 5. Взаимодействие с интерфейсом (UI)
- **Элементы:** Кнопки (`R.id.freeze_ui_button` и др.), текстовое поле для логов, полоса прогресса.
- **Связь с кодом:** Используется метод `findViewById(R.id.имя_id)`, чтобы связать элементы из XML-файла с переменными в Java.
- **События:** Используются `setOnClickListener` для обработки нажатий на кнопки.

## 6. Взаимодействие с другими компонентами
- **Сервисы:** Использует `startService` и `bindService` для связи с фоновыми службами.
- **WorkManager:** Использует `WorkManager.getInstance().enqueue()` для постановки задач (например, скачивание файла) в очередь.

## 7. Общая логика класса
Класс работает как "диспетчер". Когда пользователь нажимает кнопку, `MainActivity` решает, какой механизм фоновой работы запустить. Затем она слушает отчеты от этих механизмов и выводит их на экран в виде текста.

**Пример работы:**
1. Пользователь нажимает "Запустить в пуле потоков".
2. `MainActivity` в цикле создает 10 задач и отдает их в `fixedThreadPool`.
3. Фоновые потоки выполняют работу и "сообщают" об этом через метод `log`.
4. `MainActivity` обновляет текст на экране.

## 8. Объяснение простыми словами
Представьте, что `MainActivity` — это **Администратор в ресторане**.
- **Интерфейс (Экран)** — это зал, где сидят гости (пользователи).
- **Фоновые задачи** — это повара на кухне.
- Администратор принимает заказы у гостей и передает их на кухню.
- Чтобы гости были довольны, администратор не идет готовить сам (не блокирует главный поток), а следит за залом и сообщает гостям, когда их заказ готов.

---
**Совет для студента:** Обратите внимание на метод `onDestroy`. В Android "уходя, гасите свет" — если не остановить фоновые задачи при закрытии экрана, они продолжат работать "в никуда", пожирая ресурсы телефона.
