## 🎯 מטרת הפרויקט
- **הבעיה שנפתרת:** הדגמה של אופן ביצוע משימות ארוכות מבלי לחסום את השרשור הראשי (UI thread) באנדרואיד.
- **חשיבות:** חיוני להבטחת חווית משתמש חלקה ומניעת שגיאות "האפליקציה לא מגיבה" (ANR).
- **קהל יעד:** מפתחי אנדרואיד וסטודנטים הלומדים על עיבוד נתונים ברקע.

---

## 📌 דרישות האפליקציה
### דרישות פונקציונליות
- הדגמת הקפאת ממשק המשתמש בעת ביצוע משימות כבדות בשרשור הראשי.
- ביצוע משימות ברקע באמצעות Java `Thread` ו-`Handler`.
- ניהול משימות מקביליות באמצעות `ExecutorService` (Single ו-Fixed thread pools).
- Foreground Service למשימות ארוכות הנראות למשתמש (סימולציה של נגן מוזיקה).
- Bound Service לתקשורת בין תהליכים (שירות טיימר).
- עבודת רקע מודרנית באמצעות `WorkManager` (משימות חד-פעמיות, מחזוריות, שרשור משימות ומשימות עם אילוצים).
- הדגמה של ה-API המיושן `AsyncTask`.

### דרישות לא פונקציונליות
- **ביצועים:** שימוש יעיל בבריכות שרשורים (thread pools) ובאילוצים של WorkManager.
- **נוחות שימוש:** ממשק פשוט עם לוגים ומחווני התקדמות.
- **אמינות:** ניקוי משאבים נכון במתודה `onDestroy`.

## 🧠 ארכיטקטורה כללית
- **גישה:** ארכיטקטורה פשוטה מבוססת Activity לצורכי הדגמה.
- **רכיבים עיקריים:**
    - `MainActivity`: לוח בקרה מרכזי ויומן לוגים.
    - `Services`: `MusicPlayerService` (Foreground), `TimerService` (Bound).
    - `Workers`: מחלקות `Worker` שונות עבור `WorkManager` (הורדה, פריקה, העלאה וכו').
    - `AsyncTask`: `MyAsyncTask` להדגמת גישות ישנות.

## 🧩 תיאור מפורט של המחלקות

### 📌 מחלקה: MainActivity
- **תפקיד:** בקר ממשק המשתמש הראשי.
- **אחריות:** ניהול אינטראקציות המשתמש, הפעלת שירותים ותזמון משימות.
- **מתודות עיקריות:**
    - `onCreate()`: אתחול התצוגות, המבצעים (executors) והכפתורים.
    - `setupButtons()`: הגדרת מאזינים לכל מודולי ההדגמה.
    - `log()`: מתודה בטוחה לשרשורים להצגת הודעות לוג בממשק.
    - `onDestroy()`: שחרור משאבים וסגירת המבצעים.

### 📌 מחלקה: MusicPlayerService
- **תפקיד:** Foreground Service.
- **אחריות:** מדמה משימה ארוכה שנשארת פעילה גם כשהאפליקציה ממוזערת, ומחייבת הצגת התראה.

### 📌 מחלקה: TimerService
- **תפקיד:** Bound Service.
- **אחריות:** מתחזקת טיימר שה-Activity יכולה לתשאל בזמן שהיא קשורה אליו.

### 📌 מחלקה: WorkManager Workers (SyncWorker, DownloadWorker וכו')
- **תפקיד:** יחידות עבודה ברקע.
- **אחריות:** ביצוע משימות ספציפיות (סנכרון, הורדה, עיבוד) עם הבטחה לביצוע.

## 🔄 זרימת עבודת האפליקציה
1. המשתמש בוחר מודול (Java Threads, Services, WorkManager או Legacy).
2. לחיצה על כפתור מפעילה מנגנון רקע ספציפי.
3. האפליקציה מציגה את ההתקדמות על המסך, תוך ציון איזה שרשור מבצע את העבודה.
4. עבור שירותים ועובדים (workers), משוב ניתן באמצעות התראות מערכת או צופי מצב (observers).

## ⚙️ עבודה עם שרשורים
- **שיטות בשימוש:** `Thread`, `Handler`, `ExecutorService` (Single & Fixed), `WorkManager`.
- **סיבה:** כיסוי האבולוציה של ריבוי שרשורים באנדרואיד משרשורי Java בסיסיים ועד לספריות Jetpack מודרניות.
- **מניעה:**
    - **ANR:** משימות כבדות מועברות מחוץ לשרשור הראשי.
    - **דליפות זיכרון:** ב-`onDestroy` סוגרים את המבצעים ומנתקים את השירותים. *הערה: AsyncTask נשמר בכוונה כדי להראות היכן עלולות להתרחש דליפות.*
